# 节点监控

VVorker 提供了实时节点监控功能，帮助您了解系统运行状态和性能指标。

## 状态监控页面

访问控制台的"状态"页面即可查看节点监控信息。

### 节点列表

页面会显示所有运行中的节点：

**节点信息：**
- **节点名称**：节点的唯一标识
- **状态**：运行中 / 离线 / 异常
- **版本**：VVorker 版本号
- **运行时间**：节点启动后运行的时间
- **Worker 数量**：节点上运行的 Worker 实例数

**延迟监控：**
- **网络延迟**：到服务器的网络延迟
- **响应时间**：平均响应时间
- **最后更新**：上次更新时间

### 刷新机制

状态监控页面每 10 秒自动刷新一次，确保数据的实时性。

- **自动刷新**：页面每 10 秒自动更新数据
- **手动刷新**：点击刷新按钮立即更新数据

## 节点状态说明

### 状态类型

| 状态 | 说明 | 处理建议 |
|-----|------|---------|
| **运行中** | 节点正常运行 | 无需处理 |
| **离线** | 节点无法连接 | 检查网络连接和节点服务状态 |

### 性能指标

**网络延迟：**
- **< 50ms**：优秀
- **50ms - 100ms**：良好
- **100ms - 200ms**：一般
- **> 200ms**：较差，建议优化网络

**响应时间：**
- **< 100ms**：优秀
- **100ms - 500ms**：良好
- **500ms - 1000ms**：一般
- **> 1000ms**：较差，建议优化 Worker 代码或增加节点资源

## 节点管理

### 查看节点详情

点击节点名称可以查看更详细的信息：
- 节点配置
- 运行的 Worker 列表
- 资源使用情况
- 历史状态记录

### 节点配置

节点配置通常在服务器端进行，包括：
- 最大 Worker 数量
- 资源限制（CPU、内存）
- 监听端口
- 其他系统参数

配置文件通常位于服务器上的配置目录中。

### 节点扩容

当现有节点资源不足时，可以添加新节点：

**添加节点步骤：**
1. 在新的服务器上安装 VVorker
2. 配置节点连接到主服务器
3. 启动节点服务
4. 节点会自动出现在监控页面

**负载均衡：**
- 新节点会自动分担负载
- 可以将 Worker 分配到不同的节点
- 建议根据地理位置和性能选择合适的节点

## 日志查看

在 Worker 编辑页面的"日志"标签中，可以查看每个 Worker 的运行日志。

### 日志级别

- **INFO**：一般信息
- **WARNING**：警告信息
- **ERROR**：错误信息
- **DEBUG**：调试信息

### 日志功能

- **实时查看**：自动滚动显示最新日志
- **搜索过滤**：支持关键词搜索
- **日志导出**：可以导出日志到文件
- **清空日志**：清空当前显示的日志

## 性能优化建议

### 节点性能优化

**合理分配 Worker：**
- 将 Worker 分配到不同节点
- 避免单个节点负载过高
- 根据资源需求选择合适的节点

**增加节点资源：**
- 升级服务器 CPU 和内存
- 增加网络带宽
- 使用 SSD 硬盘

### Worker 性能优化

**减少 Worker 数量：**
- 合并功能相似的 Worker
- 使用内部服务替代多个 Worker

**优化代码：**
- 避免长时间阻塞操作
- 使用异步编程
- 合理使用缓存

**增加实例数：**
- 对于高并发 Worker，适当增加实例数
- 实现负载均衡

## 故障排查

### 节点离线

**可能原因：**
- 网络连接问题
- 节点服务停止
- 服务器故障
- 防火墙阻止连接

**排查步骤：**
1. 检查服务器是否正常运行
2. 检查 VVorker 服务是否启动
3. 检查网络连接
4. 查看节点日志文件
5. 检查防火墙配置

### Worker 无法访问

**可能原因：**
- Worker 配置错误
- 路由规则问题
- Worker 代码错误
- 资源绑定失败

**排查步骤：**
1. 检查 Worker 状态是否为运行中
2. 检查路由规则配置
3. 查看 Worker 日志
4. 测试 Worker 代码
5. 检查资源绑定状态

### 性能问题

**可能原因：**
- Worker 实例数不足
- 节点资源不足
- Worker 代码性能差
- 数据库慢查询
- 网络延迟高

**排查步骤：**
1. 查看节点监控数据
2. 查看响应时间和延迟
3. 分析 Worker 日志
4. 检查数据库查询性能
5. 检查网络状况
