# 控制台概述

VVorker 提供了一个功能完整的网页控制台，方便用户管理和监控 Worker 及相关资源。

## 访问控制台

控制台地址：`http://your-server:8888/admin`

首次访问需要注册/登录账号。

## 登录与注册

### 登录
1. 访问控制台地址
2. 输入用户名和密码
3. 点击"登录"按钮

### 注册
- 如果系统开放了注册功能，首次用户可以点击"注册"按钮创建账号
- 系统管理员也可以通过用户管理页面为用户创建账号

## 控制台界面布局

控制台采用左侧导航菜单 + 右侧内容区域的布局：

### 顶部导航
- **Workers**：Worker 管理页面
- **状态**：节点状态监控页面
- **个人中心**：用户信息和 API Token 管理
- **用户管理**：管理员专用，用户管理页面
- **资源管理菜单**：根据配置动态显示
  - PostgreSQL
  - MySQL
  - KV
  - OSS

### 主要功能模块

| 模块 | 功能描述 |
|-----|---------|
| **Worker 管理** | 创建、编辑、删除、同步 Worker |
| **状态监控** | 实时查看所有节点状态和性能指标 |
| **资源绑定** | 配置数据库、KV、OSS 等外部资源 |
| **用户管理** | 管理用户账号、角色、权限 |
| **个人中心** | 查看/管理个人 API Token |
| **协作管理** | 设置 Worker 协作者和权限 |

## 权限说明

控制台支持多租户和权限控制：

- **普通用户**：可以管理自己创建的 Worker、查看资源、管理个人 Token
- **管理员**：除了普通用户权限外，还可以：
  - 创建/删除用户
  - 修改用户密码和角色
  - 管理所有 Worker（包括其他用户的）
  - 查看全局节点状态

## 快捷操作

在控制台中，大多数页面都支持以下快捷操作：

- **新建**：创建新的 Worker、用户或资源
- **编辑**：修改配置和信息
- **删除**：删除不需要的项目
- **复制**：复制 UID、URL 等信息到剪贴板
- **刷新**：重新加载数据
