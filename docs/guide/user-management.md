# 用户管理

VVorker 支持多用户和多租户管理，每个用户可以独立管理自己的 Worker 和资源。

## 个人中心

个人中心页面允许用户查看和管理个人信息及 API Token。

### 查看个人信息
- 显示用户名
- 显示用户角色（普通用户/管理员）
- 显示创建时间

### 管理 API Token

API Token 用于通过 API 访问 VVorker 服务，是 CLI 和 SDK 工具的认证凭证。

**创建 Token：**
1. 进入"个人中心"页面
2. 点击"创建 Token"按钮
3. 输入 Token 描述（可选）
4. 点击"确认"
5. 系统会生成一个新的 Token，请**立即复制保存**（仅显示一次）

**删除 Token：**
1. 在 Token 列表中找到要删除的 Token
2. 点击"删除"按钮
3. 确认删除操作

**Token 使用场景：**
- 使用 CLI 工具 `vvcli` 时
- 使用 SDK 开发时
- 通过 API 直接访问 Worker 时

> ⚠️ **安全提示**：API Token 相当于您的账号密码，请妥善保管，不要泄露给他人。

## 用户管理（管理员）

用户管理页面仅对管理员开放，用于管理系统中的所有用户。

### 创建用户

1. 进入"用户管理"页面
2. 点击"新建用户"按钮
3. 填写用户信息：
   - **用户名**：唯一标识，用于登录
   - **密码**：建议使用强密码
   - **角色**：选择用户类型（普通用户/管理员）
   - **状态**：启用/禁用用户
4. 点击"保存"完成创建

### 编辑用户

1. 在用户列表中找到要编辑的用户
2. 点击"编辑"按钮
3. 修改用户信息：
   - 可以修改密码
   - 可以更改角色
   - 可以启用/禁用用户
4. 点击"保存"应用更改

### 删除用户

1. 在用户列表中找到要删除的用户
2. 点击"删除"按钮
3. 确认删除操作

> ⚠️ **注意**：删除用户将同时删除该用户创建的所有 Worker，此操作不可恢复。

### 用户状态管理

管理员可以启用或禁用用户账号：

- **启用**：用户可以正常登录和使用系统
- **禁用**：用户无法登录，但数据会被保留

### 角色说明

| 角色 | 权限 |
|-----|------|
| **普通用户** | - 创建和管理自己的 Worker<br>- 使用绑定的资源<br>- 管理个人 API Token |
| **管理员** | - 普通用户的所有权限<br>- 创建/删除用户<br>- 修改用户密码和角色<br>- 管理所有 Worker（包括其他用户的）<br>- 查看全局节点状态 |
