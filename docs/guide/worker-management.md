# Worker 管理

Worker 是 VVorker 的核心执行单元，每个 Worker 包含代码、配置和绑定的资源。

## Worker 列表

### 查看所有 Worker
1. 进入"Workers"页面
2. 显示当前用户可见的所有 Worker
3. 每个 Worker 显示以下信息：
   - **名称**：Worker 的唯一标识
   - **节点**：Worker 运行的节点名称
   - **实例数**：Worker 的运行实例数量
   - **描述**：Worker 的描述信息
   - **操作**：编辑、删除等操作按钮

### 创建 Worker
1. 在 Workers 页面点击"新建 Worker"按钮
2. 填写基本信息：
   - **名称**：唯一标识（建议使用有意义的名称）
   - **节点**：选择运行的节点
   - **实例数**：设置并发实例数量（1-20）
   - **描述**：简要说明 Worker 的用途
3. 点击"保存"完成创建

### 同步 Worker
- 从 Git 仓库或其他源同步 Worker 代码
- 点击"同步"按钮即可触发同步操作

### 删除 Worker
1. 在 Worker 列表中找到要删除的 Worker
2. 点击"删除"按钮
3. 确认删除操作

> ⚠️ **注意**：删除 Worker 将删除所有相关数据，此操作不可恢复。

## Worker 编辑

点击 Worker 名称进入编辑页面，编辑页面包含多个标签页：

### 属性标签

**基本信息：**
- **UID**：Worker 的唯一标识符，不可修改
- **URL**：Worker 的访问地址，可复制使用
- **名称**：修改 Worker 名称
- **版本**：当前 Worker 版本号（自动管理）
- **节点**：选择运行的节点
- **实例数**：设置并发实例数量（1-20）
- **描述**：修改 Worker 描述

**操作按钮：**
- **返回**：返回 Worker 列表
- **保存**：保存当前修改
- **打开**：在新标签页中打开 Worker URL

### 代码标签

在代码标签中可以编辑 Worker 的执行代码：

- **代码编辑器**：支持语法高亮和自动补全
- **保存代码**：点击"保存"按钮保存修改
- **运行代码**：点击"运行"按钮测试代码

**代码示例：**
```javascript
export default {
  async fetch(request, env) {
    return new Response('Hello World!');
  }
};
```

### 日志标签

实时查看 Worker 的运行日志：

- **实时日志**：自动刷新显示最新日志
- **日志级别**：INFO、WARNING、ERROR 等
- **搜索过滤**：支持关键词搜索
- **清空日志**：清空当前显示的日志

### 规则标签

配置 Worker 的路由规则：

**规则类型：**
- **域名规则**：基于域名的路由
- **路径规则**：基于 URL 路径的路由
- **Host 头规则**：基于 Host 请求头的路由

**添加规则：**
1. 选择规则类型
2. 输入匹配条件（域名、路径或 Host）
3. 选择目标 Worker
4. 保存规则

### 鉴权标签

配置 Worker 的访问控制：

**鉴权方式：**
- **公开访问**：无需鉴权
- **Basic Auth**：基于用户名密码的鉴权
- **Token 鉴权**：基于 Token 的鉴权
- **自定义鉴权**：自定义鉴权逻辑

**配置步骤：**
1. 选择鉴权方式
2. 设置鉴权参数
3. 保存配置

### 协作标签

管理 Worker 的协作者和权限：

**协作者权限：**
- **读写权限**：可以编辑 Worker 配置和代码
- **只读权限**：仅可以查看 Worker
- **管理成员权限**：可以添加/删除其他协作者

**添加协作者：**
1. 输入协作用户名
2. 选择权限级别
3. 点击"添加"按钮

详见[协作功能](./collaboration.md)

### 变量标签

管理 Worker 的环境变量和密钥：

**变量类型：**
- **环境变量**：普通的环境变量
- **密钥**：敏感信息（密码、API Key 等）

**添加变量：**
1. 输入变量名
2. 输入变量值
3. 选择变量类型
4. 保存变量

### 任务标签

管理 Worker 的定时任务：

**任务类型：**
- **定时任务**：按时间间隔执行
- **Cron 任务**：使用 Cron 表达式定义执行时间

**添加任务：**
1. 输入任务名称
2. 选择任务类型
3. 设置执行时间
4. 输入任务代码
5. 保存任务

## Worker 路由

VVorker 支持多种路由方式将请求分发到不同的 Worker：

### 基于域名的路由
配置不同的域名指向不同的 Worker。

示例：
```
example.com → Worker A
api.example.com → Worker B
```

### 基于路径的路由
根据 URL 路径将请求分发到不同的 Worker。

示例：
```
example.com/api/* → Worker A
example.com/static/* → Worker B
```

### 基于 Host 头的路由
根据请求的 Host 头进行路由，常用于反向代理场景。

## 实例管理

每个 Worker 可以运行多个实例以实现负载均衡：

**实例数量设置：**
- 最小值：1
- 最大值：20
- 建议值：根据 Worker 的资源需求设置

**实例作用：**
- 提高并发处理能力
- 提高服务可用性
- 实现负载均衡
