# 协作功能

VVorker 支持多用户协作，允许您将 Worker 分享给其他用户共同管理。

## 协作场景

协作功能适用于以下场景：

- **团队协作**：多个开发者共同开发一个项目
- **权限管理**：为不同用户分配不同级别的访问权限
- **资源共享**：多个用户共享同一个 Worker
- **临时协作**：临时邀请其他用户协助开发

## 添加协作者

### 进入协作界面

1. 进入 Worker 编辑页面
2. 选择"协作"标签
3. 如果您是 Worker 的创建者或拥有管理权限，可以看到"添加协作者"按钮

### 添加协作者步骤

1. 点击"添加协作者"按钮
2. 输入要添加的用户名
3. 选择权限级别
4. 点击"添加"完成

**示例：**
```
用户名: zhangsan
权限: 读写权限
```

## 权限级别

VVorker 支持多种权限级别：

### 读写权限
- 可以查看 Worker 配置
- 可以编辑 Worker 配置和代码
- 可以管理资源绑定
- 可以查看和管理规则
- 不能添加/删除其他协作者
- 不能删除 Worker

### 只读权限
- 可以查看 Worker 配置
- 可以查看 Worker 代码
- 不能修改任何配置
- 不能添加/删除资源
- 不能添加/删除协作者

### 管理成员权限
- 拥有读写权限的所有功能
- 可以添加/删除其他协作者
- 可以修改其他协作者的权限
- 可以删除 Worker（仅创建者）

## 协作者管理

### 查看协作者列表

在协作标签页中可以看到所有协作者：

**协作者信息：**
- **用户名**：协作用户的名称
- **权限**：当前权限级别
- **添加时间**：添加协作者的时间
- **状态**：正常/禁用

### 修改协作者权限

1. 在协作者列表中找到要修改的用户
2. 点击"编辑"按钮
3. 选择新的权限级别
4. 保存更改

> ⚠️ **注意**：只有创建者或拥有"管理成员权限"的用户才能修改权限。

### 删除协作者

1. 在协作者列表中找到要删除的用户
2. 点击"删除"按钮
3. 确认删除操作

> ⚠️ **注意**：删除协作者后，该用户将无法访问该 Worker。

## 创建协作 Worker

### 创建可协作的 Worker

有两种方式创建协作 Worker：

**方式一：先创建后添加协作者**
1. 创建 Worker
2. 进入 Worker 编辑页面
3. 在协作标签中添加协作者

**方式二：直接加入协作**
- 其他用户邀请您加入协作者列表

### 从已有 Worker 创建副本

如果您想在现有 Worker 的基础上创建新的协作 Worker：

1. 进入原 Worker 编辑页面
2. 复制代码和配置
3. 创建新的 Worker
4. 添加协作者

## 协作者的角色

### 创建者（Owner）
- 创建 Worker 的用户
- 拥有最高权限
- 可以删除 Worker
- 可以管理所有协作者

### 协作者（Collaborator）
- 被添加到 Worker 的用户
- 权限取决于授予的权限级别
- 不能删除 Worker（除非被授予管理成员权限）

## 最佳实践

### 权限分配建议

| 用户类型 | 建议权限 |
|---------|---------|
| 项目核心开发者 | 读写权限 |
| 外部合作伙伴 | 只读权限 |
| 测试人员 | 只读权限 |
| 技术主管 | 管理成员权限 |

### 安全建议

- **最小权限原则**：只授予必要的权限
- **定期审查**：定期检查协作者列表，删除不再需要的协作者
- **敏感操作**：对于敏感操作，建议使用管理员账户
- **权限升级**：如果需要临时提升权限，完成操作后及时降级

### 团队协作建议

- **代码规范**：制定统一的代码规范
- **版本控制**：建议配合 Git 使用，管理 Worker 代码
- **沟通机制**：建立团队沟通机制，避免冲突
- **测试流程**：在测试环境中验证后再部署到生产环境

## 协作限制

### 跨租户限制

- 只有同一租户（系统）内的用户才能互相添加为协作者
- 不同系统的用户无法互相访问 Worker

### 权限继承

- 协作者的权限不会自动继承
- 每个协作者的权限需要单独设置

### Worker 删除

- 只有创建者可以删除 Worker
- 即使拥有管理成员权限，协作者也不能删除 Worker

## 常见问题

### Q: 协作者可以查看其他协作者吗？
A: 可以，所有协作者都可以看到协作者列表。

### Q: 协作者可以邀请其他协作者吗？
A: 只有拥有"管理成员权限"的协作者才可以。

### Q: 创建者被删除后，Worker 怎么办？
A: 建议在删除用户前，先将 Worker 转让给其他协作者。

### Q: 如何批量添加协作者？
A: 目前需要逐个添加，可以在文档中记录所有协作者，然后批量添加。

### Q: 协作者可以管理资源绑定吗？
A: 拥有"读写权限"或"管理成员权限"的协作者可以。
